# مشروع تطبيق مفكرتي للأندرويد (التقويم + المهام + الملاحظات)

يحتوي هذا المجلد على مشروع أندرويد كامل جاهز لتحويله إلى ملف **APK** بضغطة واحدة، بالإضافة إلى ملف التطبيق المستقل الجاهز للتشغيل على الجوال.

## الطريقة 1: تحويل سريع إلى APK بدون برمجة (في دقيقة واحدة)
1. خذ الملف الموجود داخل المسار: `app/src/main/assets/index.html`
2. ارفعه على أي أداة مجانية لتحويل HTML إلى APK مثل:
   - موقع **WebIntoApp.com** أو **AppsGeyser**
   - أو تطبيق **HTML2APK** على الأندرويد
3. اضغط **Build APK** لتحميل ملف `.apk` وتثبيته مباشرة على جوالك.

## الطريقة 2: التثبيت الفوري على الجوال بدون APK (تطبيق ويب تقدمي PWA)
1. افتح ملف `PersonalPlanner_MobileApp.html` على جوالك باستخدام متصفح **Google Chrome**.
2. اضغط على القائمة العلوية **(⋮)** ثم اختر **«الإضافة إلى الشاشة الرئيسية» (Add to Home Screen)**.
3. سينزل التطبيق بأيقونة مستقلة على شاشة جوالك ويعمل بملء الشاشة ويحفظ جميع مهامك وملاحظاتك تلقائياً على الجهاز.

## الطريقة 3: بناء ملف APK عبر Android Studio أو GitHub Actions
- افتح هذا المجلد في برنامج **Android Studio** ثم اختر من القائمة العلوية:
  `Build > Build Bundle(s) / APK(s) > Build APK(s)`
- أو ارفع المشروع على حسابك في **GitHub** وسيقوم ملف `.github/workflows/build-apk.yml` المرفق ببناء ملف `app-debug.apk` تلقائياً في قسم **Actions**.
